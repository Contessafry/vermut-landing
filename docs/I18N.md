# Internationalisation

Seven locales: **en** (default), **it**, **zh** (Simplified), **es**, **de**, **fr**, **ja**.
`llms.txt` / `llms-full.txt` stay English. The claim "Pour. Click. Play.", the product name and store/tool names (Steam, Epic Games, GOG Galaxy, Wine, DXMT, …) are never translated. App UI labels (Stores, Library, Play, Run .exe, Danger zone) stay English because the app is English-only.

## Why these languages (data checked 19 October 2026)

Vermut's audience = Steam users on a Mac, so we weigh each Steam language by how common Macs are where it is spoken.

| English | 34.20% | US 26.5% | default |
| Simplified Chinese | 31.39% (+7.42 pp month on month) | CN 6.8% | 213 |
| Spanish | 4.08% (+0.75% LatAm) | ES 13.9% | 57 |
| Russian | 9.05% | RU 5.0% | 45 |
| German | 2.48% | DE 16.2% | 40 |
| Japanese | 2.41% | JP 15.0% | 36 |
| French | 2.08% | FR 17.4% | 36 |
| Portuguese (BR) | 3.70% | BR 8.0% | 29 |
| Korean | 1.37% | KR 9.3% | 13 |
| Italian | < 1% | IT 15.4% | home market |

macOS is only 1.92% of Steam overall [1], so Mac-heavy countries matter more than raw Steam share.

- **en**: largest Steam language and the US is the biggest Mac market.
- **it**: the maintainer's language and a Mac-heavy market (15.4%); native copy.
- **zh**: highest score. Caveat: the September jump of +7.4 pp looks like a survey sampling surge (it has happened before), so the real weight is lower; still in the top two.
- **es**: Spain has a high Mac share, and Spanish also reaches Latin America.
- **de**: one of Europe's highest Mac shares, and a large Steam population.
- **fr**: highest Mac share in Europe (17.4%).
- **ja**: Mac-heavy (15%) and a sizeable Steam language.

**Deferred**
- **ru** (score 45): the display face (Bricolage Grotesque) has no Cyrillic, so it would need a second display font. PayPal donations are also unavailable in Russia.
- **pt-BR** (29): next in line. It's cheap to add once the Latin locales have been reviewed.
- **ko** (13): too small for now.

## URL scheme

- English is served at `/` with no prefix. The other locales are at `/it`, `/de`, `/fr`, `/es`, `/ja` and `/zh`.
- Internally every locale is `app/[locale]`. `next.config.ts` rewrites `/` to `/en`, and `/en` 308-redirects to `/`, so English has exactly one canonical URL.
- Every page sets `rel=canonical` to itself, `hreflang` alternates for all 7 locales, and `x-default` pointing to `/`. The same alternates are in `sitemap.xml`.
- Why: no redirect is ever served to crawlers or users, all pages are statically prerendered (`generateStaticParams`), and the existing English URLs don't change.

## Language detection

There is no server redirect. A small client toast (`components/locale-suggest.tsx`) compares `navigator.languages` with the current page and, if they differ, offers a link in the visitor's own language. Dismissing it is remembered in `localStorage`. The language switcher (header `<details>` menu and footer list) shows native names, with `hrefLang` and `lang` attributes and `aria-current`.

## Implementation

- `lib/i18n/config.ts`: the locales, native names, `htmlLang` / hreflang / OG locale for each, and review status.
- `lib/i18n/dictionaries/en.ts` is the source of truth. The other locales are plain-text `Translation` objects (`lib/i18n/build.ts`) merged onto English, which keeps the ids, links, videos, tones and sources. The build fails if a translated list has a different length from the English one.
- Server only: the dictionaries are loaded lazily in server components through `next/root-params`, so no i18n code or strings ship to the client beyond what each page renders.
- Per locale: `<html lang>`, localized metadata/keywords, `og:locale` plus `og:locale:alternate`, and JSON-LD `inLanguage` and FAQ.

## Fonts and typography

- Latin locales use the existing subsets. These **lack „ (U+201E) and œ (U+0153)**: German copy uses »…«, and French avoids œ. `python3` + fontTools can be used to re-check.
- French uses no-break spaces before `: ; ? »` and after `«`.
- ja and zh use the system CJK fonts (Hiragino / PingFang, with Noto as the fallback) through `--font-cjk`, so no web-font payload is added and the English pages are unaffected. CJK headings get line-height 1.2 and no negative tracking. The English claim keeps its display styling. Japanese uses `word-break: auto-phrase`.
- Text expansion: German and French were checked at 390 px and 1440 px. The hero, nav and buttons fit.

## Guides (English only)

`/guides` and the three guide pages (`lib/guides.ts`) are served in English only, at the root
(`/run-windows-steam-games-on-apple-silicon`, …), with `hreflang="en"` and `x-default` pointing at the
same URL. `/<locale>/<guide>` returns 404, so there are no empty or duplicate translations. Translate a
guide only when a native speaker can review it, then add its locale to the hreflang map in
`components/guide-page.tsx` and `app/sitemap.ts`.
